# SDLPAL 维护版存档编辑器

专用版本 **0.1.16.0**，Windows 10+，.NET Framework 4.7.2，x86。
这是 PalSaveEditor 原仓的专用构建，保留原编辑器的主要角色、物品、杂项界面。
源码不包含游戏资源，也不改变通用版的默认构建。

r70支持隔世追凶·简单／困难／夜狼非人／非人饭制／非人饭制娱乐、梦幻2.2傀儡100%、梦幻2.2.2普通／高难、梦时空3.9x高难，以及魔改1.0、天启神佑2.0、梦幻2.11／普渡／月影／月影鼠年祈福篇、魂牵梦萦1.67简单／困难和初版分支，共18套精确资源合同。
当前版本增加仙剑DOS原版、98柔情经典速通v6，共20套内容。仅支持这些内容由SDLPal维护版生成的存档。
文件名沿用 `隔世追凶存档编辑器.exe`，窗口按当前资源显示内容名称。
退出游戏后用配置工具切换内容，再重新打开存档编辑器；物品、法术和事件长度随资源自动识别。
切换内容时不要直接交换各版本的存档，普通和高难也各自保留存档目录。

新内容包同时验证 `GAMEPLAY.INI` 的完整文件摘要、对应内容和四项资源，使用与配套引擎一致的已审核规则清单。
配置工具的选择记录必须携带一致的公式 ID、修订号与摘要；损坏、缺失或部分记录会阻止打开与保存。
旧包没有公式文件及规则选择字段时仍按原资源合同打开。独立 PAL 资源副本允许只有公式文件，打开后同样冻结其身份。
编辑期间切换或删除公式、增删选择文件，均须重新打开存档；同内容的不同公式也不能借另存为或重新选择资料绕过检查。
保存期间以只读句柄锁住资源和配置，保持 RPG 的未知尾部与 PWU1 标记；不重算或限制已有角色属性。

## 使用

将完整发布目录放在游戏 `Tools/SaveEditor`，独立双击 `隔世追凶存档编辑器.exe`。
也可给这个 EXE 创建快捷方式，或把 RPG 路径作为第一个命令行参数传入。
工具向上查找游戏目录，按该目录的 `sdlpal.cfg` 解析 `GamePath`、`SaveDirectory` 与旧 `SavePath`，
相对路径都以游戏根目录为基准。没有这两项时使用 `PAL` 资源目录和 `save` 存档目录；
r53 的 `SaveDirectory` 直接指向 `save/<内容ID>`，并核对目录的 `.content-package`。旧配置的 `SavePath` 是存档根路径，工具在其后追加 `save`。
打开对话框初始位置为解析后的存档目录，不依赖快捷方式的“起始位置”。

请在退出游戏后修改存档。选择当前内容目录中的 `1.rpg`～`5.rpg`，编辑后保存即可。
保留原存档备份默认开启，通常写入游戏 `backup/SaveTools`，另存位置不在游戏目录内时，
备份放在该存档目录的 `backup/SaveTools`。保存失败不会把内存中的修改标为已保存。
如果原存档在编辑期间被游戏或其他程序改动，工具拒绝覆盖，请重新打开最新存档。

支持六个原生角色的属性、装备、32 个物理法术槽，队伍共五条记录，至多两个随从。
姓名和物品、法术名称来自配套资源，统一显示简体，繁体 Windows 也不改变显示语言。
简体资源按 GBK 解码；兼容旧完整资源时按 Big5 解码后转简体，不依赖系统默认代码页。
姓名字库编号仍可编辑；不提供 PALDLL 姓名覆盖和自定义角色。
物品与法术分别筛选，隔世追凶的 571“隔世追凶”、575“魂息”是法术，584“金刚武神咒”是物品。
344“铜钱镖”同时有法术数据和剧情物品引用，保留双重分类。
新增版本使用各自审核的物品及法术ID，不借用隔世的对象含义。天启0x185为物品秘籍，其旧法术引用指向无效DATA记录，禁止作为法术添加；原存档中的未知数据仍原样保留。
不读取或写入 PALDLL 的 profile、角色库、技能注册表或 RPG JSON sidecar，不提供存档格式切换。

“舍我其谁”的巫后挑战存档可显示和编辑补入的10个DOS技能，关闭挑战后保存的存档仍受支持。
仅六个原本缺巫后的内容、带有效技能所有权标记的存档提供这些选项；普通存档不额外添加。
保留挑战、回头路及未知存档字段。内部角色仍是李逍遥；锁级和单人约束由游戏在读档后恢复。

## 固定资源与存档合同

打开与保存均核对配套资源 SHA256；未知或不完整组合拒绝写入。以下为隔世追凶资源。

| 文件 | SHA256 |
| --- | --- |
| SSS.MKF | `92efd5ec75dc945f3620f96f61e38879fdc0c605f5916d1143c36a4311ad57f4` |
| DATA.MKF | `c1342c3fe39e6c624c7388ad718438819d5981cf73e712d3c613548e7162dbc5` |
| WORD.DAT | `6bb07cbcdc47073a60ab53386f7d57a7cc8768c7845fcf679baf08d72a08e4fd` |
| M.MSG | `880aff05741da8d00a152b7a22661ad509817f36e7bacf52d3fae4cd8f1aceb4` |

也兼容完整的旧资源组合：相同 SSS/DATA，WORD 为
`01c2ceb561730205ca358bb31d8cb0cedf79c0b63113abc1f32905849e231811`，M.MSG 为
`7e4597015be34d8f772bdde13453106b8c9cd824a4fc69073a33bf9aac39612f`。
也兼容旧简体 M.MSG `599525efa15e0e11e65942f4139ef097bdb8a784a9fd7cb1999226ef754435de`，
它与新半角版本共用上表简体 WORD.DAT。三种组合始终要求相同的 SSS/DATA，
旧 Big5 WORD 只能配旧 Big5 M.MSG；简体 WORD 只能配两种已验证简体 M.MSG。
不能把已知的单文件摘要任意拼装。此次对白标点兼容不改变存档结构或通用版行为。
追踪：[PalSaveEditor #3](https://github.com/othercat/PalSaveEditor/issues/3)、
[游戏 #28](https://github.com/othercat/sdlpal-lostedit/issues/28)。

资源 SSS 对象表实际有 588 条，每条 12 字节；存档固定保留 **700** 个 DOS 对象槽。
关键存档偏移：现金 40、队伍 44、角色表 508、背包 1728、场景 3264、对象 5664、事件 **14064**。
事件共 **5632×32** 字节，原始五档及本版 SDLPAL 的正常存档长度都是 **194288** 字节。
编辑器不重建对象、事件、保留字段或额外尾部，允许在标准存档之后附加不对齐的未知字节并原样保存。
旧通用版 600 对象 DOS 的 12864 偏移不适用；98 版恰好也用 14064 事件偏移，不能据此当成 Win95 格式。
RPG 本身不带资源身份摘要；本工具核验配套资源和结构，不宣称可以鉴定任意伪装成同布局的数据来源。

梦幻 2.2.2 与梦时空的资源为 589 个对象、5369 个事件；存档仍是 700 个 DOS 对象槽，
事件偏移仍为 14064，标准长度为 185872 字节。物品白名单为 61～294、564、565、579；
可添加法术另按各自资源审核，不能把投掷伤害对象作为角色法术加入。
三个资源组合的完整摘要见 `MaintenanceContentProfile.cs`，普通与高难分别识别。
已打开的文档保存时重新核验原资源，期间切换到另一套合法资源也会拒绝覆盖。
游戏管理目录内只允许当前内容的存档路径；外部副本仅检查资源与结构，无法凭 RPG 鉴别其原始版本。
仙剑DOS原版使用700×12字节对象、5332事件，事件起点14064，标准长度184688。
98柔情经典速通v6使用700×14字节对象、5077事件，事件起点15464，标准长度177928。
两者均按各自四份资源完整摘要识别，不能手动转换格式，也不导入原生600对象或PALDLL扩展存档。
两者各有234个物品、106件装备；可添加法术为295～397去除空对象331和391，共101个。
内部投掷对象24不作为可学法术，v6的431条DATA记录也不等于431个可学法术。
吴强、突脸、隐形、抹怪属于运行配置；编辑器不从存档推断或改变开关。
牢局和回头路使用的保留区、对象描述脚本、事件与未知尾部在编辑后仍原样保留。
本次适配追踪：[PalSaveEditor #7](https://github.com/othercat/PalSaveEditor/issues/7)、
[游戏 #156](https://github.com/othercat/sdlpal-lostedit/issues/156)。
来源追踪：[PalSaveEditor #4](https://github.com/othercat/PalSaveEditor/issues/4)、
[梦幻整合 #121](https://github.com/othercat/sdlpal-lostedit/issues/121)、
[梦时空整合 #120](https://github.com/othercat/sdlpal-lostedit/issues/120)。

分类基于目标资源而非对象 union 的 flags 猜测：物品 61～294，加 344、567、568、569、577、583、584、585，
共 242 个 ID；可添加法术 295～397 去除空对象 331、391，加 571～576，共 107 个 ID，
并检查其 DATA 法术索引位于 108 条记录内。装备还必须具有装备 flags。
已经存在于存档中的未知值不会因为一次无修改保存被自动清理。
新编辑的物品数量和添加后的总数量上限为 99；超过上限时拒绝整个操作，不静默截断。
原档已有的未知物品或超限数量仍能原样读取、备份和无修改保存，只有明确编辑该条目时才应用新值限制。

## 构建与测试

```powershell
# 原通用版仍是默认构建；隔世版通过独立属性和输出目录隔离。
dotnet build src/PalSaveEditor.WinForms/PalSaveEditor.WinForms.csproj -c Release -p:GeshiEdition=true

# 只读 GameRoot 和 ForeignSave；测试副本、日志均位于本仓 artifacts。
./tests/run_geshi_tests.ps1 -GameRoot '游戏包目录' -ForeignSave @('其他版本/1.RPG')

# 可同时验证三种真实资源及全部六种 WORD/M.MSG 组合；每个输入只读。
./tests/run_geshi_tests.ps1 -GameRoot '半角简体游戏包' -OriginalGameRoot '原DOS游戏包' -SimplifiedGameRoot '旧简体游戏包' -Pal98GameRoot '半角简体游戏包'

# 发布到新建 artifacts/publish-geshi-时间目录，不携带游戏资源或存档。
./scripts/publish-geshi.ps1
```

`GeshiEdition=true` 使用 `bin/Geshi` 与 `obj/Geshi`，防止通用版/专用版构建缓存混用。
专用测试必须显式带这个属性，测试宿主不会启动游戏或编辑器窗口。

发布目录的 `LICENSE` 是本工具的 GPL-2.0 许可。随包 NuGet DLL 的许可单独放在 `Licenses`：
发布脚本从此次还原的 `project.assets.json` 定位包缓存，逐字节核对实际 DLL 后，
原样复制对应包的 `LICENSE*` 和 `THIRD-PARTY-NOTICES*` 文件，并保留包名/版本子目录。
`Licenses/README.txt` 与 `packages.json` 记录公开 NuGet 出处、固定版本、包摘要及各 DLL/声明摘要。
没有找到相应许可的依赖会使发布失败；脚本不改依赖版本，也不从网络另取许可文本。

专用窗口在初次完成布局后按显示器 DPI 设置角色左栏和法术栏的初始宽度；分隔条仍可拖动。
该初始布局修正不应用于通用版。

专用测试对五个原始存档覆盖：完整无修改往返、原样备份、精确字段字节范围、非对齐尾部、
角色队伍/随从边界、物品/装备/技能分类及持久化、99 数量和累加上限、历史超限值保留、32 槽上限、相对和绝对 GamePath/SavePath、
PALDLL 状态完全隔离、四资源身份错误、短文件/异版/坏头字段、外部进度冲突、备份失败和占用后重试。
测试还可读取本机实际 Win95/DOS 存档，验证拒绝后源文件未变；在 zh-CN、zh-TW、zh-HK 文化环境下检查简体名称与查找。
文化环境测试不代替繁体 Windows 的实机验收。
资源矩阵还检查三种完整组合的编码、名称、存档无修改保存和备份，三种不合法搭配的目录/打开/已打开文档保存拒绝，
以及任一核心文件摘要变化时不覆盖存档。夹具、日志只写入新建的 `artifacts` 目录。

发布前由主任务人工验收窗口布局、实际选档保存，以及游戏读入编辑副本。
模型字节往返通过不代表剧情、任意队伍组合或改动属性后的完整游戏路线已实玩验收。
