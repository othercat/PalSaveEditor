# 存档工具集中备份

编辑器与检查器保留的 RPG、人物库及配套 sidecar 备份，统一写入源文件所属游戏根目录的 `backup/SaveTools/<时间-GUID>/<原相对路径>`。游戏根只从该源文件的父目录向上查找 `PAL.EXE`；找不到时使用源文件所在目录作为根，不使用工具所在目录、当前工作目录或另一份已打开游戏的目录。因此编辑外部 RPG、另存到外部目录不会污染另一游戏包的备份。

各次备份使用独立目录。RPG 与其已备份的 sidecar 在同一目录，sidecar 在 RPG 备份名后追加原后缀。历史旁置 `.bak-*` 不删除、不移动。关闭“保留原存档备份”后不建立集中备份，现有临时文件和临时回滚行为不变。恢复仍使用保存操作返回的明确备份路径，不扫描其它批次。

创建备份前检查源文件与备份路径祖先的 reparse point，拒绝符号链接／目录联接、被文件占用的目录和已占用的备份名称。检查失败时不把备份改投其它位置，原存档保持不变。

验证：Release net472/x86 构建；两套控制台测试覆盖原字节备份、失败回滚、中文及空格路径、重复保存、源相对路径、外部另存、人物 sidecar 配套、关闭保留备份、目录占用和真实目录符号链接拒绝。可选真实 Profile 测试若缺少环境变量仍明确跳过。未进行玩家 GUI、Win7 或 ARM 实机验收。工具版本保持 0.1.6。
